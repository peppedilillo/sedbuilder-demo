# SED Builder Demo

This repo contains a demo notebook to the SSDC [SED Builder](https://gitrepo.ssdc.asi.it/sedbuilder/sedbuilder) Python client.
For more information on the package, take a look to our [documentation](https://peppedilillo.github.io/sedbuilder/api/).

## Installation

Git clone this repository, then `cd` into it and run you favourite flavour of:

```
pip install .
```

Once done, run `jupyter lab` and open the `demo.ipynb` notebook.
